LibreDWG in Coll Plan3D
=======================

Coll Plan3D reads and saves AutoCAD DWG files with the programs in this folder,
dwg2dxf.exe and dxf2dwg.exe, from GNU LibreDWG version 0.14.8597 (Windows 64-bit build).
They run as separate programs; Coll Plan3D calls them to convert DWG <-> DXF.
